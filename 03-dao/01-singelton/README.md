1. Que significa DAO?
    DAO significa Data Access Object, que en espanol se traduce como objeto de acceso a datos.

2. Cual es su responsabilidad principal?
    Su responsabilidad principal es separar y gestionar el acceso a los datos del resto de la aplicacion.

3. Que relacion tiene DAO con una base de datos?
    DAO se comunica con la base de datos para consultar, guardar, modificar o eliminar sus datos.

4. Que operaciones aparecen habitualmente en un DAO?
    Habitualmente aparecen las operaciones selectAll, selectById, insert, update y delete.

5. Que diferencia existe entre DAO y Repository?
    DAO se ocupa de como acceder y modificar los datos. Repository se ocupa de que datos necesita la aplicacion, usando uno o varios DAO si es necesario.
